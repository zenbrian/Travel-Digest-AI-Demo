# Travel Digest AI Demo 🧳✨

> Interactive Frontend Demo for **Travel Digest AI** (React 19 + Vite 7 + Tailwind CSS v4 + Leaflet)

Live Demo: [https://zenbrian.github.io/Travel-Digest-AI-Demo/](https://zenbrian.github.io/Travel-Digest-AI-Demo/)

---

## 🌟 Features

- **Interactive Scripted Demo (Acts 0 - 5)**: Step-by-step showcase of Travel Digest AI's agentic workflow.
- **Dual View Modes**: Switch between Kanban view and Interactive Leaflet Map view.
- **Route Optimization Visualization**: Comparison of original route vs. TSP-optimized route with animated indicators.
- **Pure Client-Side Deployment**: Hosted on GitHub Pages with automated CI/CD deployment via GitHub Actions.

---

## 🚀 Local Development

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build for production
npm run build
```
